Install and listen offline

Preparing the offline shell…

Only the app interface is saved offline. Library updates, imports, generation, streaming and new downloads need the server. Nothing submitted offline is queued or retried automatically.

On Android, use your browser’s Install app or Add to Home screen option when offered. Download M4A for broad player compatibility, or Opus if your player supports it. Wait for the browser’s download to finish, then open the saved file from Downloads in your audio player. Downloaded files stay on your device; buffered streaming is not an offline download.
